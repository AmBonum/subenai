## Goal

Close the missing post-publish surface on `/app/tests/$testId`: the test author must be able to see exactly who responded, how they scored, and what they answered question-by-question — without leaving the editor.

## Acceptance criteria

- New queries in `src/lib/platform/queries.ts`:
  - `useTestSessions(testId, { page, pageSize, sort, status, search })` — server-paginated; query key `["user","tests",testId,"sessions",{…}]`.
  - `useTestSessionAnswers(sessionId)` — joins `session_answers` rows with their `questions` metadata.
- New types in `src/lib/platform/types.ts`: `SessionAnswerWithQuestion`, `TestSessionsPage`.
- New file-based route `src/routes/app.tests.$testId.sessions.$sessionId.tsx` mounting `SessionDetailSheet` as a Radix Sheet overlay; closing navigates back to `/app/tests/$testId?tab=results`.
- New components `src/components/app/tests/SessionsList.tsx` + `src/components/app/tests/SessionDetailSheet.tsx`.
- Results tab in `src/routes/app.tests.$testId.tsx` rewritten: 3 KPI cards (total, completed, avg score) + `SessionsList`. Parent renders `<Outlet />` so child route mounts portal'd above the editor.
- i18n: new `editor.*` filter / sort / pagination / KPI strings, and a new `session_detail` namespace across `sk/en/cs`.
- Every interactive/semantic DOM element has a `data-testid` per CLAUDE.md naming rule (`test-sessions-list-*`, `session-detail-*`, `test-editor-kpi-*`).
- Vitest:
  - `tests/lib/platform/sessions-queries.test.ts` — query-chain shape, pagination, sort, status filter, search escape, answers join behaviour with missing question metadata.
  - `tests/components/app/tests/sessions-list.test.tsx` — empty state, loading, filter change, row open link.
- Playwright test plan: `specs/app/test-sessions-detail.md` — full TC inventory, ready for spec generation in E49.7.
- Lint 0/0, full vitest green except the 2 pre-existing `tests/functions/attachment-*` failures already red on `main`.

## Implementation notes

- KPI uses two scoped `useTestSessions` queries (pageSize 1 for `total`, pageSize 100 for `completed`). Aggregate RPC remains a follow-up if author scale exceeds 100 completed sessions on a single test.
- Search term sanitizes `%,(,)` before interpolating into PostgREST `or(intake_data->>name.ilike, intake_data->>email.ilike)` to avoid syntax break.
- `SessionAnswerWithQuestion.question.correct` is typed `unknown` — UI stringifies non-string shapes defensively.
- Parent route adds `<Outlet />` at the end; existing unit test in `tests/routes/app/test-editor.test.tsx` extends its router mock with `Outlet: () => null` for isolation.
- Side-sheet handles three states: loading skeleton → 404 (`session-detail-not-found`) → rendered detail. Empty-answers state for `in_progress` sessions.
