## Context

Phase 1 epicu E45 prepína `/app/tests/$testId` z read-only do plne
upraviteľného stavu. Schéma dnes nepozná pojem „náhodné poradie otázok"
ani lineáž testu z pôvodnej šablóny. Bez týchto dvoch stĺpcov nemá
zmysel ani editor (E45.3), ani shuffle (E45.4) na strane respondenta.

## Akceptačné kritériá

- **AC-1:** Migrácia `supabase/migrations/20260521210000_test_question_order_mode.sql`
  existuje, je idempotentná (`IF NOT EXISTS` / `DO $$ ... pg_type ... $$`) a
  obsahuje: enum `test_question_order_mode` ('fixed' | 'random'), stĺpec
  `tests.question_order_mode NOT NULL DEFAULT 'fixed'`, stĺpec
  `tests.source_template_id UUID REFERENCES templates(id) ON DELETE SET NULL`
  a čiastočný index `tests_source_template_id_idx`.
- **AC-2:** `DEPLOY_SETUP.sql` je doplnený o úplný obsah novej migrácie tesne
  pred verifikačným `SELECT count(*) ...` blokom.
- **AC-3:** `src/integrations/supabase/types.ts` je ručne synchronizovaný —
  `Row` / `Insert` / `Update` na `public.tests` obsahuje obe nové polia;
  `Enums.test_question_order_mode` a `Constants.Enums.test_question_order_mode`
  sú prítomné.
- **AC-4:** `src/lib/platform/types.ts` má pridaný typ
  `QuestionOrderMode = "fixed" | "random"` a `Test` interface dva nové
  povinné polia (`question_order_mode`, `source_template_id`).
- **AC-5:** `SEED_TESTS` v `src/lib/platform/seed.ts` a `createTest` v
  `src/lib/platform/mock-store.ts` vracajú objekty s defaultnými hodnotami
  oboch nových polí (`fixed` / `null`), aby TypeScript build prešiel.
- **AC-6:** Žiadne RLS zmeny — existujúce `tests_*` politiky pokrývajú nové
  stĺpce automaticky (sú selectované/updatované cez ten istý owner-scope).
