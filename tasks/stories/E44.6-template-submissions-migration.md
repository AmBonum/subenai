## Context

Phase B zavádza tabuľku `public.template_submissions`, ktorá nesie sledovaciu
stopu pre žiadosť používateľa zverejniť svoju súkromnú šablónu. CF Function
`functions/api/templates/precheck.ts` (E44.7) sem zapisuje AI verdikt;
admin queue v Phase C bude čítať tieto riadky pre ručné schválenie.

DDL náčrt a RLS layering sú v § Phase B pláne; konkrétne stĺpce, enum
`template_submission_status`, 4 RLS politiky, 3 indexy, state-machine
trigger sú v migrácii samotnej.

## Akceptačné kritériá

- **AC-1:** Migrácia `supabase/migrations/20260521150000_template_submissions.sql`
  existuje, je idempotentná (`CREATE TABLE IF NOT EXISTS`, enum cez `DO $$ ...
  EXCEPTION WHEN duplicate_object`) a obsahuje: enum
  `template_submission_status` so 4 hodnotami (`pending`, `approved`,
  `rejected`, `withdrawn`), tabuľku so 14 stĺpcami (id, template_id,
  author_id, author_display_name, age_rating_declared, license, status,
  precheck, precheck_passed, precheck_at, rejection_reason, reviewed_at,
  reviewer_id, submitted_at, updated_at), 3 indexy (`template_idx`,
  `author_idx`, čiastočný `admin_queue_idx WHERE status='pending'`),
  trigger `touch_template_submissions_updated_at` a state-machine trigger
  `forbid_template_submission_illegal_transitions`.
- **AC-2:** State-machine trigger povolí prechody: `pending→approved`,
  `pending→rejected`, `pending→withdrawn`, `rejected→pending` (re-submission).
  Akýkoľvek iný prechod statusu raisne výnimku — defense-in-depth nad RLS.
- **AC-3:** RLS politiky (4): `template_submissions_author_read` (autor číta
  svoje), `template_submissions_author_insert` (autor insertuje so svojím
  user-id), `template_submissions_author_withdraw` (autor môže UPDATE iba
  pending → withdrawn cez kombináciu USING + WITH CHECK + state-machine
  triggerom), `template_submissions_admin_all` (admin FOR ALL).
- **AC-4:** `DEPLOY_SETUP.sql` je doplnený o presný obsah migrácie pred
  *Verification* sekciu.
- **AC-5:** `src/integrations/supabase/types.ts` ručne rozšírený o
  `template_submissions: { Row, Insert, Update, Relationships }` blok
  vrátane FK `template_submissions_template_id_fkey`, plus enum
  `template_submission_status` v `Enums` bloku.
- **AC-6:** Migrácia obsahuje self-check komentár s 4 SQL dotazmi
  (policies count = 4, indexes count = 4 vrátane pkey, triggers count = 2
  bez internal, enum hodnoty = 4).
- **AC-7:** Žiadne PII v indexe; `author_display_name` je snapshot
  v čase submission (prežije profile rename / account delete v Phase D
  edge case 7.1).
