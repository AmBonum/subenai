# E48.4 — `/app/help/contact` authenticated form + `/app/help` landing

**Epic:** E48 — Support contact form + admin ticketing system
**Effort:** `S` (~½ day)
**Priority:** `P0`
**Status:** 🟡 Ready
**Branch:** `feature/E48-support-ticketing`
**Commit prefix:** `feat(app):`
**Dependencies:** E48.3 (reuses `<SupportContactForm>`)

## Context

Authenticated users opening "Help" from the `/app` sidebar should hit a
landing card that includes a "Kontaktovať podporu" entry pointing at a
pre-filled form. Profile data (email + display_name) auto-populates; no
Turnstile (the JWT already proves humanity).

## Acceptance criteria

- **AC-1:** Route `/app/help/index.tsx` — landing page with two cards:
  - **FAQ** (link to existing `/app/help/faq` if present; otherwise a placeholder noting "FAQ pripravujeme" — out of scope for this epic).
  - **Kontaktovať podporu** (link to `/app/help/contact`).
- **AC-2:** Route `/app/help/contact.tsx` — renders `<SupportContactForm variant="authenticated" />`. Pre-fills `email` and `name` from `useSession()` + `profiles` lookup; both fields shown read-only (locked icon) so the user cannot impersonate.
- **AC-3:** Submission posts to the same `/functions/api/support-ticket-create.ts`, but with the auth JWT in the `Authorization` header. The function detects auth and:
  - Skips Turnstile verification
  - Skips honeypot enforcement (still rendered for parity but ignored)
  - Skips per-IP rate limit (uses a per-user-id limit instead: 10 tickets per 24h)
  - Sets `submitter_user_id = auth.uid()` on the inserted row
- **AC-4:** Success: redirect to `/app/help/tickets/$id` (own-ticket read view in E48.4-stretch below). Toast: "Žiadosť bola odoslaná, odpovieme do {N} pracovných dní". The view is authenticated-only (RLS gates).
- **AC-5:** Stretch — `/app/help/tickets/index.tsx`: list of this user's own tickets (`submitter_user_id = auth.uid()`). Card-style list with status badge + last-update timestamp. Empty state: "Zatiaľ ste neodoslali žiadnu žiadosť o podporu."
- **AC-6:** Sidebar entry: `/app/help` added to the existing `/app` sidebar (icon: `HelpCircle` from lucide). Placement: under "Účet", above "Odhlásiť sa".
- **AC-7:** Test IDs follow CLAUDE.md naming: `app-help-landing-card-faq`, `app-help-landing-card-contact`, `app-help-contact-form-*` (re-uses `SupportContactForm` testids with `app-` prefix overridden via prop).
