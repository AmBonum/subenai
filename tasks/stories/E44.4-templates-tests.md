## Context

Phase A potrebuje pokrytie na štyroch vrstvách (Vitest unit, Vitest +
RTL component, DB SQL contract, Playwright e2e stub) tak, aby boli pred PR
merge splnené sekcie 2.2 a 3.2/3.3 DoD. Plnohodnotný e2e spec príde až s
Phase D (verejná galéria), tu pripravujeme len smoke stub a POM základ.

Štruktúra testov a názvy súborov sú zadané v § Phase A — story detail
(E44.4) plánu; tento story file ich kodifikuje ako AC.

## Akceptačné kritériá

- **AC-1:** `tests/lib/platform/queries.templates.test.ts` (Vitest, mocked
  Supabase) pokrýva:
  - `useMyTemplates` vystavuje `.eq('owner_id', auth.uid())` a
    `.order('updated_at', { ascending: false })`.
  - `usePublicTemplates` vystavuje OR predikát `owner_id.is.null` +
    `(visibility.eq.public.AND.status.eq.published)`.
  - `useDuplicateTemplate` posiela INSERT so správnym setom polí
    (`owner_id`, `visibility='private'`, `status='draft'`, `fork_of`,
    `title` so suffixom `' (kópia)'`) a **neposiela** `slug`,
    `published_at`, `author_display_name`.
  - `useUpdateOwnTemplate` a `useDeleteOwnTemplate` majú explicitný
    `.eq('owner_id', auth.uid())`.
- **AC-2:** `tests/components/app/templates/TemplatesPage.test.tsx` (RTL +
  user-event) overuje:
  - Render oboch tabov a panelov.
  - Prepínanie tabov mení URL search (`?tab=mine`).
  - Filter bar je sticky (presence test, nie visual).
  - Štyri empty states sa renderujú podľa `(tab, filter)` matrice.
  - Skeleton sa renderuje počas `isLoading`.
- **AC-3:** `tests/components/app/templates/TemplateCard.test.tsx`:
  - Vlastnená karta zobrazuje kebab so 4 položkami (Upraviť, Duplikovať,
    separator, Vymazať).
  - Cudzia karta zobrazuje kebab len s Duplikovať.
  - Klik na kartu (mimo kebabu) volá `onUse(id)`.
  - Klik na kebab nevolá `onUse` (overuje `stopPropagation`).
- **AC-4:** `tests/components/app/templates/TemplateDeleteConfirm.test.tsx`:
  - Po otvorení má focus tlačidlo Zrušiť (nie destructive).
  - Esc zatvára dialog.
  - Click-outside **nezatvára** (AlertDialog default).
  - `aria-describedby` cieli na element s presným Slovak textom o dôsledku.
  - Klik na Áno, vymazať vola `onConfirm`.
- **AC-5:** `tests/db/templates_v2_ownership.test.ts` (regex assertions nad
  migračným SQL stringom):
  - 4 enum CREATE TYPE príkazy.
  - 6 nových RLS politík + admin policy (`templates_read_defaults`,
    `templates_read_own`, `templates_read_public_published`,
    `templates_insert_own`, `templates_update_own`, `templates_delete_own`,
    `templates_admin_all`).
  - 3 indexy (`templates_owner_visibility_idx`,
    `templates_public_published_idx`, `templates_fork_of_idx`).
  - 2 triggery (`templates_touch_updated_at`,
    `templates_forbid_default_mutation`).
  - 15 INSERT-ov s `owner_id NULL`, `visibility 'public'`, `status
    'published'`.
  - Žiadny príkaz nemení `forbid_attempt_score_changes`.
- **AC-6:** `e2e/specs/app/templates.spec.ts` (Playwright, stub):
  - Happy-path smoke: log in → `/app/templates` → vidieť 15 verejných →
    duplikovať jednu → objaví sa v Moje tab → upraviť názov → vymazať.
  - Plný spec príde s Phase D; tento je `test.describe.skip` ak fails CI
    sporadically a obsahuje TODO komentár odkazujúci na E44.4 (vrátiť
    `skip` len ak Phase D blokuje, inak nech beží zelený).
- **AC-7:** `e2e/poms/app/Templates.ts` POM existuje a vystavuje gettery
  pre všetkých 47 test-idov z appendixu D § 9 (alebo aspoň tie, ktoré
  e2e stub používa — zvyšok ako placeholder s TODO pre Phase D).
- **AC-8:** Žiadny `.skip` / `.only` v Vitest súboroch. `npm run lint`
  0/0, `npm test` zelený, `npm run e2e:browser -- templates` zelený voči
  lokálnemu stacku.
