## Context

Klient-side strana submission flow: na `/app/templates` na *Moje* tabe pri
každej **vlastnej** šablóne pribúda položka *Odoslať na zverejnenie* v kebab
menu. Dialóg konzumuje verdict z `/api/templates/precheck` (E44.7) a vykreslí
buď úspech (zelený), pending-admin (žltý) alebo error (červený) stav.
Verbatim Slovak strings pre súhlas pochádzajú z [Appendix B](../E44-appendix-B.md) § 3.

## Akceptačné kritériá

- **AC-1:** Nový komponent `src/components/app/templates/TemplateSubmitDialog.tsx`
  obsahuje sekvenčný formulár (author display name confirmation →
  age-rating select → CC BY 4.0 consent checkbox → collapsible details →
  attribution preview) a tri verdict stavy (success / held-for-admin /
  error).
- **AC-2:** Verbatim Slovak copy pre consent label, details heading,
  details body, attribution preview line — exact match s Appendix B § 3.1
  až § 3.4 (žiadne parafrázovanie; checkbox label = 198 znakov, details
  body ≈ 145 slov).
- **AC-3:** Submit tlačidlo aktívne **iba ak** consent zaškrtnutý
  + age-rating vybraný + nie je práve in-flight. Cancel kedykoľvek.
- **AC-4:** `useSubmitTemplate` mutácia v `src/lib/platform/queries.ts`:
  POST `/api/templates/precheck` s `Authorization: Bearer <session.access_token>`,
  body `{ template_id, title, description, question_texts,
  age_rating_self_declared, cc_by_consent: true }`. Na non-2xx hodí
  `SubmitTemplateError` s `code` z response body — dialog renderuje
  konkrétnu Slovak hlášku per code: `rate_limit_user_daily`,
  `rate_limit_global`, `rejected_cooldown_active`, `budget_exhausted`,
  generic.
- **AC-5:** `TemplateCard` má novú prop `onSubmitPublic` + nový kebab
  item `templates-card-{id}-action-submit` viditeľný iba ak
  `owner_id === currentUserId && visibility !== "public"` (admin už
  schvalené šablóny sa nesmú znova podávať).
- **AC-6:** `/app/templates` route má state pre submit dialog (open +
  ktorá šablóna) a vykresľuje `<TemplateSubmitDialog>` na page-leveli.
- **AC-7:** Slovak/EN/CS i18n: `templates.submission.*` namespace
  v `src/i18n/locales/sk/tests.json` + zrkadlené v `en/` a `cs/`
  (Slovak je canonical pre legálny text; EN/CS sú vernými prekladmi,
  nie legálne záväzné).
- **AC-8:** Test-ids podľa CLAUDE.md kebab-case rule:
  `templates-submit-dialog`, `…-author-name`, `…-age-rating-select`,
  `…-consent-checkbox`, `…-consent-details-toggle`, `…-consent-details-body`,
  `…-attribution-preview`, `…-submit-button`, `…-cancel-button`,
  `…-loading-state`, `…-verdict-success`, `…-verdict-held`,
  `…-verdict-error`, `…-close-after-verdict`.
- **AC-9:** A11y: focus trap (Dialog primitive), Escape zatvára (Cancel
  ekvivalent), Tab order = author name → age select → checkbox →
  details toggle → submit → cancel, `aria-labelledby` na dialog title,
  `aria-describedby` na body.
