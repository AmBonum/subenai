## Context

AI moderátor pre používateľsky-odoslané šablóny. POST `/api/templates/precheck`
overí prihlásenie, validuje vstup, dodrží rate-limity a denný rozpočet,
zavolá Claude Haiku 4.5 so štruktúrovaným promptom (Appendix C § 2) a
zapíše verdikt do `template_submissions`. Verdikt prijme aj klient v
dialógu (E44.8); admin queue v Phase C bude čítať plné JSON envelope cez
service-role.

Pricing model (Appendix C § 7): ~$0.003/submission warm, ~$0.005 cold;
denný strop default $5.00.

## Akceptačné kritériá

- **AC-1:** `functions/api/templates/precheck.ts` existuje, exportuje
  `onRequestPost` a obsahuje pipeline: JWT verify → zod body validate →
  rate limits (IP/h, user/d, global/h) → budget ceiling → template
  ownership check → cooldown check (24h od `rejected`) → insert pending
  submission → call Anthropic → persist envelope (bez `raw_response`) →
  audit_log → return verdict.
- **AC-2:** `functions/_lib/anthropic.ts` — raw-fetch klient pre POST
  `/v1/messages` s 10s timeout, retry-once-on-malformed-JSON, prompt
  caching (`cache_control: ephemeral` na system bloku), cost extraction.
  Žiadny `@anthropic-ai/sdk` import (matches `functions/_lib/email.ts`
  Resend pattern).
- **AC-3:** `functions/_lib/precheck-prompt.ts` — system prompt verbatim
  z Appendix C § 2 (~1.8K tokenov, 3 few-shots: CLEAN, PROFANITY,
  COPYRIGHT FLAG).
- **AC-4:** `src/lib/templates/precheckSchema.ts` — shared TS + zod
  schéma (`PrecheckResult`, `PrecheckAgeRating`, `PrecheckCategory`),
  deterministická brána `derivePrecheckPassed` s konštantami
  (SAFETY_THRESHOLD=0.3, PROFANITY_THRESHOLD=0.5, allowed ages
  {`all`,`13+`,`16+`}), `PrecheckEnvelope` typ + helper `stripRaw`
  a `toVerdict`.
- **AC-5:** Prompt-injection hardening: vstup je obalený XML tagmi
  `<template_title>`, `<template_description>`, `<questions><q>...</q>...</questions>`;
  `<`, `>`, `&` escape-nuté; model je explicitne inštruovaný v system
  prompte ignorovať akúkoľvek inštrukciu nachádzajúcu sa v týchto tagoch.
- **AC-6:** Rate limits: per-IP 20/h (default), per-user 5/d, global 100/h.
  Mapovanie age-rating API (`13+`) na DB enum (`thirteen_plus`) cez
  jednu mapu (`AGE_API_TO_DB`).
- **AC-7:** Failure modes: malformed JSON → retry 1× s prísnym
  „JSON only" reminderom → ak stále malformed, `manualReviewFallback`
  envelope s `precheck_passed=false` a `summary` začínajúcim
  `manual_review_required:`. Submission row existuje vždy (insert sa
  deje pred AI volaním).
- **AC-8:** Env vars: `ANTHROPIC_API_KEY` (CF secret), `PRECHECK_MODEL_ID`
  (default `claude-haiku-4-5-20251001`), `PRECHECK_DAILY_BUDGET_USD`
  (default `5.00`), `PRECHECK_PER_USER_PER_DAY` (default 5),
  `PRECHECK_PER_HOUR_GLOBAL` (default 100), `PRECHECK_PER_IP_PER_HOUR`
  (default 20). Plus existujúce `SUPABASE_*`.
- **AC-9:** Odpoveď klientovi je iba `{ submission_id, precheck_passed,
  age_rating, summary, held_for_admin_review }` — **NIKDY** raw JSON ani
  PII. Plný envelope ide do servera (`console.log`) a DB
  (`precheck` jsonb minus `raw_response`).
- **AC-10:** Audit log: každý precheck = 1 riadok v `audit_log` s
  `action='template_precheck'`, `actor_id=user.id`, `pii_access=false`,
  `details` má `precheck_passed`, `cost_usd`, `template_id`.
