**Status:** ✅ Done (this PR)

## Scope

Senior-level expansion of the Layer A coverage for the `/app/tests`
respondent drill-down feature. Three spec files now cover ~50 TCs against
the existing seeded mock:

- `e2e/specs/app/test-sessions-detail.spec.ts` — extended from 19 → ~45 TCs.
  Existing TC-01..TC-19 retained verbatim where the assertion still holds;
  TC-05 rewritten to a single-page pagination edge test (multi-page
  traversal is a Layer B concern). New describe blocks: status-narrowing,
  side-sheet entry surfaces, side-sheet rendering details, not-found /
  invalid routes, empty / zero data, defensive defaults, edge data shapes,
  combined / stateful UX.
- `e2e/specs/app/test-sessions-list.spec.ts` — NEW. Covers POS-01..POS-04
  (the `/app/tests` index) + adjacent negatives (empty owner, no-match
  search, filter cycle).
- `e2e/specs/security/csv-injection.spec.ts` — NEW. UI XSS sweep against
  the side-sheet for representative payloads from
  `tests/security/xss-payloads.ts`, plus direct unit-level assertions on
  `functions/_lib/csv.ts:serializeCsvRow` for SEC-08..SEC-18 (full
  download contract lives in Layer B).

## Source-of-truth changes (in scope for THIS PR)

- `src/components/app/tests/SessionDetailSheet.tsx`:
  - Score line always renders, with a `session-detail-score-formatted`
    inner span that surfaces "—" for null score (NEG-23 / EDGE-03 / 04).
  - Stale-question answer rows render an "—" placeholder with a new
    `session-detail-stale-question` testid + `data-stale-question="true"`
    attribute on the row (NEG-22).
  - Respondent identity is hidden when the session does not belong to
    the URL test id — closes the latent leak the IDOR TC exposed.
- `src/components/app/tests/SessionsList.tsx`:
  - Respondent label cell truncates at 260px with a `title` attribute
    carrying the full text — accessibility + NEG-25 contract.
  - New `test-sessions-list-row-<id>-label` testid for assertions.
- `e2e/seed/sessions.ts`: added `extended` flag that materialises 6 new
  fixtures (score 0, 100, null, long name, RTL name, stale-question)
  plus `test_questions: []` in the returned tables so `useTest()` no
  longer 404s on the unmocked relation. The original 19 TCs see the
  same 6-row shape they did before.
- `e2e/mocks/supabase/envelope.ts`: two hardening fixes for the Layer A
  parser:
  - `applyParsedQueryWithTotal` separates pre-slice count from post-slice
    rows so `useTestSessions({ pageSize: 1 })` (the KPI driver) reports
    the real total via `Content-Range`.
  - `or=(col.op.v,col.op.v)` parsing — disjunction of leaf predicates,
    plus JSON-path column accessor (`intake_data->>name`) — unblocks the
    Layer A search ILIKE that previously degraded to "all rows".
