## Context

`/app/templates` dostáva plný UI prepis nad novou schémou (E44.1) a queries
vrstvou (E44.2). Pribúdajú dva taby („Verejné" / „Moje"), kebab DropdownMenu
s akciami (Použiť, Duplikovať, Upraviť, Vymazať), tri dialogy (Edit,
Duplicate, Delete-via-AlertDialog), 47 test-idov, klávesové skratky a 14 UX
úprav vyplývajúcich z auditu v
[Appendix D](../E44-appendix-D.md) (1 BLOCKER + 7 MAJOR + 5 MINOR + 1 NIT).
SEO / public gallery (`/sablony`) prichádza až v Phase D — `/app/templates`
zostáva `noindex`.

Detailné komponentové členenie, copy stringy, ARIA spec, color-contrast
overenia a kompletný test-id audit sú v
[`tasks/E44-appendix-D.md`](../E44-appendix-D.md). Tento story file vlastní
**how** a acceptance criteria; appendix vlastní **why**.

## Akceptačné kritériá

- **AC-1:** Route `src/routes/app.templates.tsx` je prepísaný (~80 LOC) ako
  kompozícia nových komponentov v `src/components/app/templates/`:
  `TemplatesTabs.tsx`, `TemplatesFilterBar.tsx`, `TemplateCard.tsx`,
  `TemplateActionMenu.tsx`, `TemplateEditDialog.tsx`,
  `TemplateDuplicateDialog.tsx`, `TemplateDeleteConfirm.tsx`,
  `TemplateGridSkeleton.tsx`.
- **AC-2:** Tabs („Verejné" / „Moje") sú perzistované v URL query parametri
  `?tab=public|mine` cez `Route.useSearch()` + `validateSearch`. Default
  pri prvej návšteve = `public`. Prepínanie tabov zachováva filter state
  (search + category + sort).
- **AC-3:** Filter bar je **sticky** pod app-shell hlavičkou
  (`sticky top-[var(--app-shell-header-h,4rem)]`), obsahuje search,
  category select (so Slovak `gdpr_purpose` labels — fix BLOCKER-u D1.8),
  sort select (Najnovšie / Najstaršie / Abecedne A–Z, perzistované v
  `localStorage("app.templates.sort")`) a results count `"X z Y"`.
- **AC-4:** Karta je celá klikateľná (wrapper `<button>` / `<Link>` =
  `Použiť`); kebab `<DropdownMenu>` v rohu má `e.stopPropagation()` +
  `onPointerDown={e.stopPropagation()}`, aby nešpustil row-click.
- **AC-5:** Pre vlastnenú kartu kebab obsahuje: Upraviť, Duplikovať,
  separator, Vymazať (destructive). Pre cudziu / predvolenú kartu kebab
  obsahuje iba Duplikovať. Položka „Odoslať na zverejnenie" je v kóde
  pripravená za feature-flag (Phase B), v Phase A skrytá.
- **AC-6:** `TemplateEditDialog` (Radix `<Dialog>`): initial focus na
  title input; tab order Title → Description → Category → Question picker
  → Cancel → Save; Esc zatvára; click-outside zatvára; ARIA `aria-labelledby`
  + `aria-describedby` cez `DialogTitle` / `DialogDescription`.
- **AC-7:** `TemplateDuplicateDialog`: initial focus na title input
  pre-fillnutý `"{originalTitle} (kópia)"`; akcia INSERT cez
  `useDuplicateTemplate`; success toast `"Šablóna bola pridaná do tvojich
  kópií."`; po úspechu prepne tab na `?tab=mine`.
- **AC-8:** `TemplateDeleteConfirm` používa Radix `<AlertDialog>` (nie
  `<Dialog>`): initial focus na **Zrušiť** (cez ref + `onOpenAutoFocus`),
  click-outside **nezatvára**, confirm tlačidlo je destructive variant s
  copy `"Áno, vymazať"`, description (`aria-describedby`) explicitne
  uvádza dôsledok: `"Tvoja kópia bude nenávratne odstránená. Originálnu
  verejnú šablónu to neovplyvní."`.
- **AC-9:** Štyri empty states podľa `(tab, filter)` matrice (D1.7) so
  Slovak copy zo § 5.1–5.3 appendixu. Pre `(mine, no-copies)` empty state
  obsahuje CTA `"Pozrieť verejné"`, ktoré prepne tab.
- **AC-10:** Karty grid: `grid gap-4 sm:grid-cols-2 lg:grid-cols-3
  xl:grid-cols-3`, počas `isLoading` sa renderuje `TemplateGridSkeleton` s
  6 skeleton kartami v rovnakom gride.
- **AC-11:** Klávesové skratky: `J` / `K` posun fokusu medzi kartami;
  `Enter` = Použiť; `D` = Duplikovať; `E` = Upraviť; `Del` = Vymazať. Všetky
  skratky **ignorované**, keď `event.target` je `<input>`, `<textarea>`
  alebo `contenteditable`. Inline tooltipy a `<DropdownMenuShortcut>`
  ukazujú písmená.
- **AC-12:** Slovak i18n stringy pridané do `src/i18n/locales/sk/tests.json`
  pod `templates.*` (12 base stringov z plánu + ~25 placeholderov / chýb /
  toastov z appendixu § 5). Plurals pre `questions_count` cez Slovak pravidlá
  (1 → `one`, 2–4 → `few`, 5+ → `many`) ak `tFor` plurals podporuje;
  inak naimplementovať `pluralSk(count)` helper.
- **AC-13:** Test-idy podľa § 9 appendixu — všetkých 47 idov v
  kebab-case `templates-<component>-<element>(-{id})`. Žiadny class /
  `nth-child` selektor v žiadnom teste.
- **AC-14:** Page zostáva **`noindex`** (meta `robots` v route header)
  — SEO surface je Phase D na `/sablony`.
- **AC-15:** A11y — WCAG 2.1 AA: keyboard nav prejde celý flow, focus
  trap v dialógoch (Radix default), color contrast pasuje (§ 7 appendixu),
  `prefers-reduced-motion` rešpektovaný (Skeleton + dialog animácie).
- **AC-16:** Mobile (375 px): 1 stĺpec, kebab 44×44, primary `Použiť`
  44 height, taby `max-sm:h-11`, search/select tiež `max-sm:h-11`.
