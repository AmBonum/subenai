## Context

User-decision 2026-05-21: namiesto okamžite-aktívnej free-tier verzie
funkciu šíkujeme ako preview PRO funkciu. Tlačidlo je v UI viditeľné,
ale disabled s PRO badge + tooltipom „bude dostupné v pláne PRO".
Infraštruktúra (E45.13 + E45.14) je hotová na strane backendu.

## Akceptačné kritériá

- **AC-1:** Nový komponent `InviteEmailDialog` (Dialog z Radix) —
  textarea pre recipienti (čiarka/medzera/riadok-oddelené), live
  validátor `{valid, invalid}`, voliteľný `include_password` checkbox
  (zobrazí sa len keď test má heslo) s warningom + password input.
- **AC-2:** Submit posiela na `/api/tests/send-invites` s `Authorization`
  hlavičkou z aktuálnej Supabase session. Toast success / partial /
  error. Pri 2xx + 0 failed → dialog sa zavrie + reset; pri 4xx/429 ostane
  otvorený s error toastom.
- **AC-3:** `src/lib/billing/pro-features.ts` — feature-flag systém:
  - `PRO_FEATURES` katalóg s `email_invites`,
  - `userHasPro()` (zatiaľ pevne `false`),
  - `isProFeatureLocked(id)` helper.
- **AC-4:** `<ProBadge />` komponenta (sk: „PRO" pill, amber štýl,
  Sparkles ikona) v `src/components/billing/`.
- **AC-5:** V `/app/tests/$testId` route je *Pozvánky e-mailom* tlačidlo
  iba pre `published` testy. Keď je locked (`isProFeatureLocked === true`):
  - `disabled`, `aria-disabled`, `data-pro-locked="true"`
  - inline `<ProBadge />`
  - obalené v Radix Tooltip so Slovak copy z i18n
    (`editor.invite_pro_tooltip`)
- **AC-6:** i18n sk/en/cs: `editor.invite_button` + `editor.invite.*`
  (29 kľúčov) + `editor.invite_pro_tooltip`.
