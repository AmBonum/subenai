## Context

Nové RLS kontrakty z E44.1 vyžadujú dve oddelené read cesty: predvolené +
publikované verejné (pre tab „Verejné") a vlastné (pre tab „Moje"). Zároveň
musíme pridať tri nové mutácie (`useDuplicateTemplate`,
`useUpdateOwnTemplate`, `useDeleteOwnTemplate`), rozšíriť TS typ `Template`
o nové stĺpce a zachovať spätnú kompatibilitu pre `/app/tests/new`, ktorý
templates konzumuje len ako zdroj otázok.

Detailný náčrt API a TS typu je v § Phase A — story detail (E44.2) pláne.

## Akceptačné kritériá

- **AC-1:** `src/lib/platform/types.ts` rozširuje `Template` o 10 nových
  stĺpcov (`owner_id`, `visibility`, `fork_of`, `status`, `license`,
  `author_display_name`, `age_rating`, `slug`, `published_at`, `updated_at`)
  a 4 union enumy. Žiadny existujúci konzument nedostane breaking change
  (všetky polia sú additive).
- **AC-2:** `src/lib/platform/queries.ts` exportuje dva nové hooky:
  - `useMyTemplates()` — vracia riadky, kde `owner_id = auth.uid()`
    (každá viditeľnosť), zoradené podľa `updated_at desc`.
  - `usePublicTemplates()` — vracia uniu `owner_id IS NULL` plus
    `visibility = 'public' AND status = 'published'`, zoradené podľa
    `published_at desc`, `created_at desc` ako fallback.
- **AC-3:** Tri nové mutácie sú exportované:
  - `useDuplicateTemplate()` — INSERT s `owner_id = auth.uid()`,
    `visibility = 'private'`, `status = 'draft'`, `fork_of = source.id`,
    `title = source.title + ' (kópia)'`. Po úspechu invalidates
    `useMyTemplates`.
  - `useUpdateOwnTemplate()` — UPDATE s explicitným `eq('owner_id',
    auth.uid())` aj keď RLS to vynucuje (defense in depth). Aktualizuje
    `title`, `description`, `question_ids`, `gdpr_purpose`. Po úspechu
    invalidates obe listing query.
  - `useDeleteOwnTemplate()` — DELETE s explicitným `eq('owner_id',
    auth.uid())`. Po úspechu invalidates `useMyTemplates`.
- **AC-4:** Pôvodné `useTemplates`, `useCreateTemplate`, `useUpdateTemplate`,
  `useDeleteTemplate` zostávajú exportované, ale s JSDoc `@deprecated`
  poznámkou odkazujúcou na náhradu. Slúžia len pre admin code-paths
  (`/admin/tests`).
- **AC-5:** `/app/tests/new` (jediný non-admin konzument) je migrovaný na
  `usePublicTemplates`. Žiadna iná zmena správania v tomto route — read
  cesta je rovnaká „čítaj zoznam, klonuj otázky do testu".
- **AC-6:** Všetky query keys (`['templates', 'mine']`, `['templates',
  'public']`) sú konzistentné cez všetky hooky, takže `invalidateQueries`
  ich trafí všetky relevantné.
- **AC-7:** TypeScript strict prejde bez nových `any`, `// @ts-ignore`
  ani `// @ts-expect-error`. `npm run lint` ostáva 0/0.

## Podúlohy

### Implementácia
- [ ] Rozšíriť `Template` typ v `src/lib/platform/types.ts` o 10 stĺpcov.
- [ ] Splitnúť `useTemplates` v `src/lib/platform/queries.ts` na
      `useMyTemplates` a `usePublicTemplates` so správnymi `.eq()` /
      `.or()` predikátmi.
- [ ] Pridať `useDuplicateTemplate`, `useUpdateOwnTemplate`,
      `useDeleteOwnTemplate` ako TanStack Query mutations s
      `invalidateQueries` v `onSuccess`.
- [ ] Označiť pôvodné štyri hooky `@deprecated` v JSDoc.
- [ ] Migrovať `src/routes/app.tests.new.tsx` (alebo aktuálne pomenovaný
      file) na `usePublicTemplates`.

      správne polia.
- [ ] Smoke test `/app/tests/new` — render, výber šablóny, klon do testu,
      bez regresie oproti súčasnému správaniu.
