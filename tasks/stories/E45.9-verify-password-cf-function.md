## Context

Tento endpoint je front door pre password-locked test. Spec je v
`tasks/E45-appendix-A.md` (STRIDE T1-T14, rate-limit matrix §3, cookie
attrs §2.4, audit-log row §5.2).

## Akceptačné kritériá

- **AC-1:** `functions/api/tests/verify-password.ts` existuje s `onRequestPost`.
- **AC-2:** Pipeline: body-shape → JWT/Supabase env check → L3 daily quota
  (200/day/share) → L2 global per-share (50/h) → L1 per-IP+share (5/15min)
  → RPC `verify_test_password` → audit-log INSERT → mint cookie & 200,
  alebo 401/429.
- **AC-3:** Cookie scope `Path=/t/<share_id>` (NIE `/`), `HttpOnly`,
  `Secure`, `SameSite=Lax`, `Max-Age=1800`, nikdy `Domain=` (host default).
- **AC-4:** Jitter 100ms ± 25ms (`JITTER_BASE_MS + (Math.random() * JITTER_SPREAD_MS - JITTER_SPREAD_MS / 2)`)
  pred KAŽDOU odpoveďou — T7 timing oracle uzavretý.
- **AC-5:** `audit_log` riadok per attempt (incl. rate-limited a unknown-share).
  `actor_name = 'respondent:' || hashIp(ip)` (SHA-256 base64url 12 char,
  nerekonštruovateľný), `details.outcome ∈ {pass, fail, rate_limited,
  share_locked, unknown_share}`.
- **AC-6:** Nový hook `signRespondentPwdToken` / `verifyRespondentPwdToken`
  v `functions/_lib/jwt.ts` — HS256, role `"respondent"`, iss `"subenai.sk"`,
  pv carrier. Separátna claim shape od `EduAuthorClaims` (T13).
- **AC-7:** Preflight endpoint `functions/api/tests/check-password.ts`
  (GET) — vracia `{has_password, gated, reason}`. Reasons: `no_cookie`,
  `expired`, `bad_signature`, `wrong_share`, `password_changed`. Bez
  rate-limitu (signature check je lacný; bcrypt sa nevolá).
