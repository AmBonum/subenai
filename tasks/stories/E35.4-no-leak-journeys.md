# E35.4 — No-leak browser-journey suite (Playwright)

**Epic:** [E35 — Security & GDPR compliance audit + test coverage expansion](../PLAN-2026-05-20-E35-security-compliance-audit.md)
**Effort:** `M` (≤ 2 days)
**Priority:** `P1` (must)
**Status:** 🟡 Ready

## Context

Today's `e2e/specs/consent/cookie-banner.spec.ts` covers banner UX —
buttons, copy, ARIA. It does **not** verify the GDPR contract that
matters most: with consent rejected, the browser sends zero bytes to
any third-party domain. Likewise it does not verify that the consent
version bump retriggers the banner, or that share buttons render plain
links (no FB/X pixel script injection).

This story adds Playwright specs that intercept network traffic and
assert outbound-domain allowlists per consent state.

## User story

> As a GDPR-compliant operator, **I want** automated proof that
> reject-all keeps every third party out of the browser session,
> **so that** I can hand a regulator the CI log instead of a promise.

## Acceptance criteria

- **AC-1**: New POM `e2e/poms/security/NetworkSentinel.ts` exposes:
  - `outboundDomains(): Promise<string[]>` — unique third-party
    domains contacted since the sentinel was attached.
  - `cookieNames(): Promise<string[]>` — cookie names currently set.
  - `localStorageKeys(): Promise<string[]>` — localStorage keys
    currently set.
- **AC-2**: New `specs/security/no-leak-journey.md` test plan in
  English describes every scenario below before any spec is written.
- **AC-3**: New `e2e/specs/security/no-leak-journey.spec.ts` covers:
  - **Reject-all baseline**: Fresh visit, click "Odmietnuť všetko",
    navigate every public route (`/`, `/test/quick`, `/privacy`,
    `/cookies`, `/about`, `/manage-support`, `/sponsors`, `/blog`,
    `/support`). Assert `outboundDomains()` is a subset of
    `["subenai.sk", "*.supabase.co", "challenges.cloudflare.com"
    (only on /manage-support), "js.stripe.com" (only on /support)]`.
    Assert ZERO requests to `googletagmanager.com`,
    `google-analytics.com`, `*.facebook.com`, `*.twitter.com`,
    `*.linkedin.com`, `analytics.google.com`.
  - **Accept analytics only**: Click "Prispôsobiť", enable analytics,
    save. Assert GA endpoints now appear in `outboundDomains()`.
    Assert marketing endpoints still absent.
  - **Version-bump**: Pre-seed `localStorage["iiq_consent"]` with a
    stale `version` field, reload, assert banner reappears.
  - **Share buttons**: Render `/r/$shareId` (with a known-good
    fixture share_id), click each share button, assert it opens a
    plain `https://` link (verified via `context.on("page")`) with
    no FB SDK / pixel script loaded in the parent page.

## Dependencies

- Blocked by E35.1 (the cookie/processor declarations on `/cookies`
  define the exact allowlist).

## Risks

| Risk | Mitigation |
|---|---|
| `page.on("request")` misses requests fired before the listener attaches | NetworkSentinel attaches in `beforeAll` before any navigation. |
| Stripe/Turnstile load asynchronously and a race breaks the spec | Use `waitForLoadState("networkidle")` before reading `outboundDomains()`. |
| Test pollutes localStorage across runs | Each test uses a fresh `context` via the base fixture. |
