# E48.6 — `/admin/tickets` index — sortable, filterable, searchable

**Epic:** E48 — Support contact form + admin ticketing system
**Effort:** `M` (~1.5 days)
**Priority:** `P0`
**Status:** 🟡 Ready
**Branch:** `feature/E48-support-ticketing`
**Commit prefix:** `feat(admin):`
**Dependencies:** E48.1 (schema)

## Context

The admin ticketing console index. Mirrors the layout of `/admin/users`
(see E46 dossier code) — sticky filters + search row, table below,
pagination footer. Slovak labels. Admin + AAL2 gate (matches all other
PII-bearing admin routes).

Replaces the 3-line stub at `src/routes/admin/support.tsx` (kept as a
redirect for back-compat: `/admin/support` → `/admin/tickets`).

## Acceptance criteria

- **AC-1:** Route `src/routes/admin/tickets/index.tsx`. Loader uses `requireRole('admin')` + AAL2 gate from `src/integrations/supabase/role-middleware.ts`. Sidebar entry "Podpora" (icon: `LifeBuoy` from lucide) replaces the existing /admin/support stub link.
- **AC-2:** Table columns:
  - Status badge (coloured chip — `new` = blue, `in_progress` = amber, `waiting_user` = purple, `resolved` = green, `archived` = grey)
  - Category badge
  - Subject (truncated to 80 chars + ellipsis; full on hover)
  - Submitter name + email (linked to `/admin/users/$id` if `submitter_user_id` set; else plain text)
  - Created at (relative + absolute on hover via `<time title>`)
  - Last updated at (relative)
  - Attachments count (with `scan_status` aggregate icon: green check if all clean, red shield if any infected, amber clock if any pending)
  - Assigned-to (admin avatar; blank if unassigned)
- **AC-3:** Filter chips above the table:
  - Status (multi-select, default `[new, in_progress, waiting_user]`)
  - Category (multi-select)
  - Scan status — `Any | Has infected | All clean | Pending`
  - Assignee — `Any | Unassigned | Me | <other admins>`
  - Toggle: `Zobraziť archivované` (default off)
- **AC-4:** Search input — full-text over `subject + body + submitter_email + submitter_name`. Debounced 300ms. Query string `?q=…` so URLs are shareable.
- **AC-5:** Pagination — 50 rows per page, query string `?page=N`. Total count shown.
- **AC-6:** Row action: click row → navigate to `/admin/tickets/$ticketId` (E48.7). Right-click / 3-dot menu deferred to later.
- **AC-7:** Empty state: when no tickets match filters, render `<EmptyState>` with copy "Žiadne žiadosti tohto typu" + CTA "Vyčistiť filtre".
- **AC-8:** Test IDs: `admin-tickets-row-{ticketId}`, `admin-tickets-filter-status-{value}`, `admin-tickets-filter-category-{value}`, `admin-tickets-search-input`, `admin-tickets-page-next`, `admin-tickets-page-prev`, `admin-tickets-empty-state`, `admin-tickets-clear-filters`.
- **AC-9:** Performance — first paint < 500ms with 1000 tickets in DB. Index on `(status, created_at DESC)` + GIN index on `to_tsvector('simple', subject || ' ' || body)`.
- **AC-10:** Realtime updates — when a new ticket lands (via Supabase Realtime channel `support_tickets_admin` from E48.9), a toast appears "Nová žiadosť: {subject}" and the table refreshes its first page.
