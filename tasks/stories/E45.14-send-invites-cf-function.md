# E45.14 — CF Function `/api/tests/send-invites`

**Epic:** [E45](../PLAN-2026-05-21-E45-test-detail-editor.md)
**Effort:** `M`
**Status:** ✅ Done
**Commit prefix:** `feat(api):`

## Akceptačné kritériá

- **AC-1:** `functions/api/tests/send-invites.ts` s `onRequestPost`.
  Auth-required (`Authorization: Bearer <Supabase JWT>`).
- **AC-2:** Body: `{ test_id, recipients[], include_password, password? }`.
  Recipients deduplikované, lowercased, max **50/send** (Q3).
- **AC-3:** 4-vrstvové rate-limits (revidované B2 free tier):
  - L1: 50 pozvánok / IP / hod
  - L2: 500 pozvánok / hod globálne
  - L3: 50 pozvánok / autor / deň
  - L4: 50 pozvánok / test / deň
- **AC-4:** Owner-only — RLS aj body-level re-check (`owner_id = auth.uid()`).
  Status musí byť `published`; draft/archived → 400 not_published.
- **AC-5:** `include_password = true` overí plaintext cez RPC
  `verify_test_password` (anti-rotation: po zmene hesla v inom tabe sa
  nedostane do mailu stale heslo).
- **AC-6:** Resend send per-recipient cez `_lib/email.sendEmail`; audit
  row INSERT **až po Resend 2xx** (R6 mitigation). `pii_access = true`,
  `details = {recipient_email_hash, included_password, resend_message_id}`,
  recipient ako sha256-hex (E11 PII register compliant).
- **AC-7:** Partial-success je legálny — Resend chyba na jednom recipientovi
  nepreruší batch; vrátime `{sent, failed, errors[]}` 200.
- **AC-8:** Idempotency key per `(test, recipient_hash[:16], today)` — retry
  z toho istého autora v ten istý deň na ten istý recipient nedoručí dvakrát.

## Definition of Done

- 15 testov green (auth, body shape, owner, rate-limits, audit, partial success,
  dedup, password verify, hashEmail).
- Resend free tier — kým platený plán neexistuje, endpoint je PRO-gated
  na frontu (PR rozhodnutie z 2026-05-21). Funkcionalita je *pripravená*,
  nie odovzdaná koncovým používateľom.
