# E55 — Academy Merge — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** Merge /blog + /courses into one interactive /academy (DB-unified), with w3schools-style `[[quiz:id]]` questions, SEO-preserving redirects, and consolidated tests.

**Architecture:** Extend `blog_posts` with content_type/difficulty/minutes/emoji; migrate 31 courses into the DB; a shortcode pre-pass renderer reuses the quiz engine; new `/academy` routes + `_redirects` retire `/blog` + `/courses`.

**Tech Stack:** Supabase, TanStack Start routes, react-markdown, existing quiz engine (AnswerFeedback/QuestionCard/VisualBlock), Vitest + jest-axe, Playwright.

**Design spec:** `tasks/PLAN-2026-06-28-E55-academy-merge.md` (authoritative — read for full rationale).

**Cutover strategy:** E55.1–E55.4 are ADDITIVE (new columns, new components, new routes alongside the old) → land incrementally, site stays live. E55.5 (delete /blog+/courses + redirects) + E55.6 (test consolidation) are the breaking cutover → land last, together.

## Task E55.1: Schema — academy columns on blog_posts

**Files:**
- Create: `supabase/migrations/<ts>_academy_columns.sql`
- Modify: `DEPLOY_SETUP.sql`, `src/integrations/supabase/types.ts`
- Test: `tests/db/academy-columns.test.ts`

- [ ] **Step 1: Write the migration** (additive, safe; defaults keep 82 articles as articles)

```sql
-- E55.1 — Academy: unify courses into blog_posts.
alter table public.blog_posts
  add column if not exists content_type text not null default 'article'
    check (content_type in ('article','lesson')),
  add column if not exists difficulty text
    check (difficulty in ('beginner','advanced')),
  add column if not exists estimated_minutes integer,
  add column if not exists hero_emoji text;

create index if not exists idx_blog_posts_content_type on public.blog_posts (content_type);
```

- [ ] **Step 2: Mirror into `DEPLOY_SETUP.sql`** (append the same alter+index in the blog section).
